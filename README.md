# FlyToBhutan

A responsive Bhutan travel website demo built with plain HTML, CSS and JavaScript.

## Files
- index.html
- styles.css
- script.js

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
Push the three files to a repository and enable GitHub Pages from the repository settings.

## Design palette
- Bhutan Yellow: #FFCD00
- Bhutan Orange: #FF6720
- White: #FFFFFF
- Black: #000000
